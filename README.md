# Rich Post — редактор rich-постов для Telegram

Веб-редактор постов с расширенной разметкой Telegram (Bot API 10.1+, метод `sendRichMessage`):
заголовки, таблицы, списки задач, сноски, формулы LaTeX, раскрывающиеся блоки, коллажи, кнопки, медиа.
Бот присылает готовый пост вам в личку, а дальше вы пересылаете его куда нужно.

Работает на вебхуках, без VPS и без базы данных: целиком разворачивается на Vercel (бесплатного тарифа хватает).

## Возможности

- Markdown и HTML режимы (синтаксис из [документации Rich messages](https://core.telegram.org/bots/api#rich-messages))
- Панель инструментов, горячие клавиши (`Ctrl+B/I/U/K`, `Ctrl+Enter` — отправить)
- Живое превью в стиле Telegram (формулы через KaTeX, спойлеры, таблицы, сноски)
- Шаблоны и шпаргалка с примерами
- Загрузка фото/видео/аудио/файлов прямо в пост (до ~3 МБ на пост; крупное — по ссылке)
- Автосохранение черновика в браузере
- Работает как Telegram Mini App (кнопка в боте) и в обычном браузере (по личной ссылке)

## Структура

```
api/webhook.js   — вебхук бота (/start, /link)
api/send.js      — отправка поста через sendRichMessage
api/me.js        — проверка авторизации
api/chats.js     — проверка канала/группы перед добавлением в список «Куда»
api/setup.js     — регистрация вебхука, команд и кнопки меню
lib/telegram.js  — вызовы Bot API, подписи и проверка initData
public/          — фронтенд (статический, без сборки)
```

## Деплой на Vercel

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Залейте проект в GitHub и импортируйте его на [vercel.com/new](https://vercel.com/new)
   (Framework Preset: **Other**, настройки сборки не нужны). Или через CLI:
   ```bash
   npx vercel --prod
   ```
3. В настройках проекта Vercel → **Environment Variables** добавьте:
   - `BOT_TOKEN` — токен бота (обязательно)
   - `ALLOWED_USERS` — необязательно: ваш Telegram id (или несколько через запятую), чтобы ботом не пользовались посторонние
   - `APP_URL` — необязательно: если используете свой домен
4. Сделайте **Redeploy**, чтобы переменные применились.
5. Откройте в браузере `https://<ваш-проект>.vercel.app/api/setup` — должен вернуться `"ok": true`.
   Это зарегистрирует вебхук, команды и кнопку «Редактор» в меню бота.
6. Напишите боту `/start` и нажмите «Открыть редактор».

## Публикация прямо в канал или группу

Кроме отправки себе в личку, бот может публиковать пост сразу в канал. Пост выходит от имени канала, без пометки «переслано от бота».

1. Добавьте бота в канал **администратором** с правом «Публикация сообщений». В группу — обычным участником.
2. Бот пришлёт вам в личку сообщение «Бот подключён к …» с кнопкой «Писать в этот чат». Она откроет редактор, где канал уже выбран.
   Канал можно добавить и вручную: кнопка ⚙︎ рядом с полем «Куда», затем `@username` или числовой id.
   Чтобы узнать id приватного канала, перешлите боту любой пост оттуда.
3. Выберите канал в поле «Куда» и нажмите «Опубликовать». Перед публикацией редактор спросит подтверждение.

Права проверяются на сервере **при каждой отправке**: в канал может публиковать только его администратор с правом публикации, в группу — только её участник. Список каналов хранится в браузере, а в Mini App — ещё и в CloudStorage Telegram, поэтому он виден на всех устройствах.

> После обновления до этой версии откройте `/api/setup` ещё раз: вебхук должен начать получать события `my_chat_member`.

## Как устроена авторизация

Отдельной базы нет — пользователь определяется подписью:

- **В Mini App** фронтенд отправляет `Telegram.WebApp.initData`, сервер проверяет его HMAC-подпись токеном бота.
- **В браузере** бот выдаёт ссылку вида `/#token=<id>.<подпись>`; подпись — HMAC от id пользователя на токене бота.
  Ссылка сохраняется в `localStorage`. Не передавайте её другим: по ней можно слать вам сообщения от бота.
  Чтобы аннулировать все ссылки, перевыпустите токен бота в @BotFather (`/revoke`), обновите `BOT_TOKEN` и снова откройте `/api/setup`.

Пост всегда отправляется только в личку тому, кто авторизован, — чужим людям через ваш бот ничего не отправить.

Вебхук защищён заголовком `X-Telegram-Bot-Api-Secret-Token`, который выводится из токена бота.

## Локальный запуск

```bash
npx vercel dev
```

Для работы бота локально нужен публичный HTTPS-адрес (например, через туннель) и `APP_URL` с ним;
редактор и превью работают и без этого.

## Ограничения

- Лимиты Telegram: 32 768 символов, 500 блоков, 50 медиа, 20 колонок в таблице.
- Тело запроса на Vercel ограничено 4,5 МБ, поэтому загружаемые файлы — до ~3 МБ на пост. Крупные медиа вставляйте ссылкой `![](https://…)`.
- Превью приблизительное: итоговый вид определяет клиент Telegram. Если Telegram отклонит разметку, текст ошибки покажется в редакторе.
